# 长笛五音动机

- `phrase.soundforge`：可直接打开的完整可编辑工程，内嵌采样。
- `phrase.wav`：同一引擎渲染的 48 kHz 立体声 PCM16 音频。
- `instrument.sfinstrument`：在乐器声部中导入的独立乐器包。
- `notes.json`：原生按拍音符事件，BPM 120。
- `conversion.json`：每个录音的来源、许可证、原始轮替/循环字段和转换说明。

录音来自 [VSCO 2 Community Edition](https://versilian-studios.com/vsco-community/)，CC0-1.0。感谢 Versilian Studios / Sam Gossner 及原库贡献者。此次使用 A4、E5、C6 三个根音的断奏录音，每个根音包含三档实际力度、两个重复样本；音域沿用作者映射，未填补采集集合中缺失的音域，没有擅自启用持续循环或伪造连奏。

五音动机为本项目原创，用重复、一次上行变化与力度对比演示采样选择。它是演奏功能示例，尚未进行主观音质评审。按 `docs/instruments.md` 的命令可从本地采集清单重新生成全部文件。
