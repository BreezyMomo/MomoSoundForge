# 声音资源与本地库

[English](sound-resources.en.md) · [使用手册](user-guide.md)

## 音源、乐器与作品资源

- **录音**是一份独立音频，保存原始音高、调音和增益，可单独试听、编辑和入库。
- **合成器**保存发声算法、参数声明和默认值。试听音频不是合成器本体。
- **乐器**保存名称与音符发声绑定；一个区域可使用录音或合成器快照。定义不含旋律。
- **音乐／音效**保存可编辑声音内容，可包含录音、合成声音、乐器演奏、组合和效果。

录音与合成器合称音源。乐器是名称与音符绑定表，不再引入“乐器包”类型。内置乐器引用的每份录音都单独出现在音源列表中，显示原始音高、力度与版本；同一份录音被多个区域引用时只计一次。乐器定义通过类型筛选单独查看。

作品中的声音层是独立实例。修改、删除或切换库不联动已有作品；作品和资源包携带继续编辑所需的算法、映射和录音。

## 创建和使用

打开顶栏 **声音资源库**，或左侧 **管理资源**。侧栏与管理窗口共用内置及当前本地库的资源，按类型、来源、分类、名称搜索，支持收藏和最近使用。默认显示音源，录音逐份列出并显示总数，没有按乐器折叠或在卡片中切换录音的入口。搜索覆盖全部资源，首批显示 48 项，点击“继续显示”加载下一批。卡片上的主要操作随类型显示“用这份录音创作”“用它创作”“使用乐器写音符”“添加到作品”。内置乐器仍按现有音区提供，不自动扩充原录音范围。

在 **管理资源** 中：

1. **创建／打开本地库…**：选择一个文件夹。空文件夹自动创建目录；已有库先校验目录再打开。个人资源的正式保存位置是该文件夹。
2. **导入录音…**：添加一份录音；单音录音可设置真实原始音高，非单音素材可保留“未标记音高（保持原速）”。不会自动检测音高。**新建合成器**：选择基础振荡器或自定义声音表达式，编辑生成逻辑、参数、默认值，试听后保存。
3. **新建乐器**：左列逐行显示全部音符（C-1～G9），右列是对应音源。列表连续滚动，每个音符只显示一次，没有音区切换、分组或跳转。空行点击“添加音源”；已有音源点击名称切换。打开的就是统一声音库，可选择内置或本地的录音、合成器。窗口中的“添加音源”快捷入口复用声音库原有的创建／上传／导入流程，保存成功后自动绑定到这行音符。每行可试听；音域共用、力度、演奏方式等放在折叠的“更多设置”中。
4. **开始空白音乐／音效**：在作品中添加资源、编写音符；**上传音频创建音乐／音效…** 可先检查文件，再保存为资源或加入作品。
5. **保存当前作品为资源**：保存完整当前作品。可显式选择已有音乐／音效作为保存目标，发布新版本；另存新资源生成新 ID。此处不随声音层选择暗中改变保存范围。

合成器创建一个可调整时长和参数的合成声音；乐器创建空谱，随后在音符编辑器写旋律。内置资源修改后保存为自己的资源。有未保存修改时，关闭会在屏幕中央弹出确认窗口；“继续编辑”或 Esc 保留草稿，“放弃修改并关闭”只退出当前编辑窗口。

逐音符绑定默认只改变当前音符。已有音域共用设置保持原样，新增单音设置优先负责这个音符；移除单音设置后会恢复使用共用声音。合成器保留生成器快照；录音复用原始音频并保留已设置的原始音高、调音和增益。例如 C3 录音绑定 C4 时自动升高一个八度，行内显示“由 C3 变调”。未标记音高的录音保持原速；共享音域也不自动变调。音源在库中更新或删除，不会联动乐器里的副本。取消选择或取消创建不改变绑定；添加成功但绑定失败时，已保存的音源保留并提示重新选择。

乐器编辑器只提供逐行试听：播放中的那一行显示停止按钮，点击其他音符会切换试听，播放结束后自动恢复。底部保留保存、导出和使用乐器写音符，不再提供全局试听／停止。

## 本地文件夹

```text
我的声音库/
  index.json
  resources/
    <资源ID>-v<版本>-<SHA256>.sfresource
```

`index.json` 使用 `momo.sound-library/v1`，记录库 ID、名称与资源元数据。资源文件为自包含 JSON，使用 `momo.sound-resource/v1`。索引只保存元数据与波形预览，算法和录音在资源文件内。保存或导入乐器时，引用的录音与合成器同时作为独立条目入库；相同音频及发声设置复用已有条目，删除乐器不删除音源。乐器仍携带依赖快照，便于搬运与保持声音。旧版本地库可在管理资源中点击“将旧版乐器音源加入声音库”，只补齐音源与索引，不修改乐器文件或版本。每次保存先写新文件、回读校验，再更新目录；版本冲突拒绝覆盖。并发写入使用浏览器锁，提交时复核目录与连接。删除前确认，删除当前资源及其工具生成的历史文件，不删除外部文件；不提供回收站或历史版本浏览。

关闭本地库只断开连接。切换不复制、合并资源；已有作品保持自己的内容。浏览器 IndexedDB 仅保存文件夹连接与作品草稿，日常资源读写不回退到旧浏览器库。文件夹读写需要桌面 Chrome / Edge；内嵌浏览器的目录选择支持取决于宿主。授权失效时点击“重新授权连接”。复制整个库文件夹即可备份，跨地址打开同一文件夹可读取同一批资源。

旧“我的音效”和旧定义库可通过“迁入旧浏览器资源”迁移。迁入后逐项读回校验，原浏览器数据保留作备份。迁移使用稳定 ID，重复迁移复用相同内容，内容冲突明确报错。旧数据保留不是第二套可编辑资源库。

每份资源文件最多 40 MiB；工程原有的 24 MiB 解码录音、64 个直接资产、输入层数、嵌套和音符预算仍有效。目录最多 2000 个资源、4 MiB。远程库只预留来源与读取接口，当前没有订阅、网络下载、更新或同步实现。

## 合成器算法

现有 `oscillator-v1` 保持原声音规则；新增 `expression-v1`。两者沿用 `momo.synth/v1` 定义容器。表达式例子：

```text
sin(2*pi*phase + brightness*sin(6*pi*phase)*exp(-3*t))
```

其中 `brightness` 是用户声明的参数，需有稳定变量名、显示名称、最小值、最大值、步长和默认值。使用实例可修改参数值，库定义保持不变。

- 输入：`t` 秒、`phase` 0～1（按当前频率累积）、`frequency` Hz、`duration` 秒、`velocity` 0～1、`pi`。
- 运算：数字、括号、`+ - * /`；函数 `sin/cos/tanh/abs/exp/sqrt/floor/fract/min/max/pow/clamp`；`noise()` 使用固定种子。
- 输出：有限数值，限制到 −1～1，再进入现有包络、滤波、失真和声音处理链。
- 限制：最多 2048 字符、256 token、128 运算、16 层表达式和 16 个参数；整份渲染有独立计算预算。不是 JavaScript，不支持属性访问、赋值、循环、外部访问、自定义状态反馈或插件代码。

这可以定义新的解析合成公式，例如调频、加法谐波与噪声组合。当前没有可视化节点连线、任意有状态算法模块或实时流式演奏。试听、波形和导出共用引擎，固定种子可复现。代码检查不代替创作者实际听审。

乐器中的合成器区域保存 `synth` 快照、可选 `synthValues`，`assetId` 为空字符串。演奏音符提供音高与力度；`releaseSeconds` 控制松键余音。普通录音区域继续保存根音、音域、力度、轮替、释放与已验证循环信息。不会允许任意播放器递归嵌套作为音符来源。

## 用户与 AI 导入

**导入资源文件…** 接受 `.sfresource`、`.sfsynth`、`.sfinstrument`、`.soundforge`；先打开草稿供检查与试听，保存到本地库后两处列表同步出现。同 ID 的资源不会静默覆盖，需显式另存，或打开本地原资源编辑。

资源包结构：

```json
{
  "schema": "momo.sound-resource/v1",
  "id": "example-fm-bell",
  "version": 1,
  "name": "FM Bell",
  "kind": "synth",
  "category": "magic",
  "description": "A parameterized bell generator",
  "preview": [],
  "payload": { "schema": "momo.synth/v1", "...": "完整合成器定义，见 examples/resources" }
}
```

`kind: recording` 的 payload 是 `{schema:"momo.recording/v1", asset:SampleAsset, rootMidi:number|null, tuneCents, gainDb, releaseSeconds, loop?}`。`rootMidi:null` 在绑定时生成 `fixedPitch:true` 的录音区域；其他音高按原始音高变调。录音预览与加入作品使用同一录音渲染流程。

`kind: instrument` 的 payload 是完整 `.sfinstrument`；`kind: sound` 是带 root 播放器的原生工程。资源 ID 与内部定义身份分别保存；工程里每次使用携带独立快照。

离线创作工具支持：

```sh
node cli.mjs schema
node cli.mjs resource-validate --input fm-bell.sfsynth
node cli.mjs resource-pack --input fm-bell.sfsynth --out fm-bell.sfresource
node cli.mjs resource-render --input fm-bell.sfresource --out preview.wav
node cli.mjs resource-project --input fm-bell.sfresource --out editable.soundforge
```

命令输出不覆盖文件。`resource-render` 产生临时试听；`resource-project` 对乐器创建空谱。MCP 的 `sound_resources` 查询内置或用户明确要求的本地资源，`sound_import_resource` 将资源作为新条目保存到已连接文件夹，要求新鲜作品 snapshot 和当前库 destination；不替用户选择文件夹，不修改作品或覆写资源。`sound_edit` 可用 `local:<ID>` 插入库资源。网页和 AI 共用校验与资源预算。
