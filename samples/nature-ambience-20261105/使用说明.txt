自然环境音效基础包

20 个工作片段，来自 11 个发布者原始文件，按 8 种用途组织：野外风声、雨落水面、雨落地面、独立雷鸣、短鸟鸣、鸟鸣环境、溪流环境、虫鸣环境。另有林间清晨、风雨雷鸣、溪边虫鸣三个可编辑组合。

同一长录音的不同截取片段不代表不同原始录音。manifest.json 逐条保留原件、来源页、作者、许可、校验和、截取位置和处理方法；originals 保留发布者文件原始字节，licenses 保留网页证据及来源清单。BigSoundBank 证据来自页面渲染后的 main DOM 或可见正文，具体类型逐条标记；OpenGameArt 保留原始 HTML。

本包选择 CC0-1.0。Random Sounds Samples 提供 OGA-BY 3.0 与 CC0 双重许可，本包选择 CC0。每个来源的实际声明保存在网页快照中。

工作副本为 48 kHz 双声道 PCM16 WAV，转换不会恢复有损录音的原始质量。新版雨声、雷声来自 BigSoundBank 的单声道 48 kHz / 24 bit WAV，设备注明为 SoundDevices MixPre-3 + Sennheiser ME66；雷声来源明确注明 without rain。部分鸟鸣和虫鸣的发布者原件是 OGG，来源格式如实记录。庭院虫鸣来自普通笔记本麦克风，保留相应背景噪声；溪流环境含远处鸟鸣，不作为纯净流水单声源。

首次天气候选经用户试听反馈含其他环境声音，已从工作片段及原件目录撤下；来源、原始 SHA256 与被替换片段 ID 保存在 excluded 中，避免重新收录。新版雨声按水面和地面分别组织，不将雨中雷鸣混录作为独立雷声。组合示例仍允许用户自行叠加。

环境循环选取 10–12 秒的片段，使用 0.25 秒等功率交叉处理接缝，首尾另加 5 毫秒防爆音渐变。独立鸟鸣、雷鸣按所选事件保留起音与自然尾音。所有片段使用记录在清单中的高通及固定增益，原件不修改。引擎的试听、波形与导出使用同一原生工程。

内置库按需下载工作片段，不下载整个长原件。打开环境音效后会恢复其循环范围；可继续编辑范围与接缝处理。普通单次导出仍遵循导出面板的设置。

采集与复核：
  python tools/collect-nature-sfx.py --ffmpeg <FFmpeg路径>
  python tools/collect-nature-sfx.py --verify-only
依赖 Python 3、numpy、beautifulsoup4；FFmpeg 版本记在每个片段的处理记录中。下载文件和压缩包有 SHA256 锁定；发布者文件改变时必须重新核对，不能静默替换。BigSoundBank 的 WAV 通过公开下载表单获取；已纳入版本的原件可直接复核与重建，缺失时按报错提示从来源页选择 WAV 下载到指定缓存。仅提取选择的 ZIP 成员，不直接解压归档路径。

测量验证覆盖来源、字节校验、有效音量、播放范围、循环边界和原生渲染一致性，不等于完成了人工听感验收。试听合辑和测试记录保存在当前工作树的 test-results/nature-qa 中，供进一步试听。
