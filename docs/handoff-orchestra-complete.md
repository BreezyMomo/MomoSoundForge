# 管弦乐器音库交接

后续 AI 新增、整理或替换乐器前，必读 [乐器整理与替换规则](instrument-library-rules.md)。采用完整乐器定义，按实际对应关系替换旧条目，修复中英文显示名；不能恢复主仓库音源清单或把演示工程当成完整乐器。较早审查文档中的“候选／未发布”和旧构建命令是当时记录，当前状态以本文件及资源仓库为准。

管弦乐器资源按音库独立维护。主工程不保留采集目录、SFZ 映射、许可证副本或生成音频；这些内容随资源仓库的自描述目录发布。

需要新增或替换乐器时，在资源仓库完成来源、许可、映射、音频哈希和完整依赖验证，发布新的固定 `index.json`，再更新主站订阅。应用只依赖远程协议，不依赖某个仓库的路径结构。

验证当前版本：

```sh
npm test
npm run build
```

浏览器中还需验证远程目录加载、乐器试听、完整依赖下载、保存重开和断开音库后的新增音符。
