## 本轮选择及依据

补齐独奏小提琴、单簧管、次中音长号。旧入口每件仅三份代表录音，部分单录音定义覆盖整个 MIDI 键盘，不足以作为真实乐器使用。使用同一作者的完整源录音和 SFZ 映射补齐，不能称为已经换成另一套来源，也不能称为全部管弦乐器都已经完成。

- 独奏小提琴：90 份录音，长音、跳弓（界面称“短弓”）；两者音区都是 G3–C7（MIDI 55–96）。
- 单簧管：97 份录音；长音 D3–F#6（MIDI 50–90），短音 D3–F6（50–89）。
- 次中音长号：86 份录音；长音 Bb1–F4（MIDI 34–65），短音 Bb1–Bb4（34–70）。

范围表示所有映射的边界；具体音符、力度和演奏方式以实际映射为准，不把边界之间没有对应录音的格子补成虚构覆盖。保留原件全长、音区、力度层、替换录音、音准微调、起音与释放参数。禁止自动加未经核实的循环点、跨全键盘移调或四秒截断。

来源为 [VSCO 2 CE 官方仓库](https://github.com/sgossner/VSCO-2-CE) 和 [作者说明](https://versilian-studios.com/vsco-community/)，CC0。录音固定提交 `440300901dfe9275fd84e0b7763af1f8443ae62e`，SFZ 固定提交 `6dd651d55dde97fd4028699be9d4481f26917891`。源文件逐个校验 Git blob、SHA-256，六份 SFZ 和原授权副本保存在 `samples/orchestra-complete-20261107/`。

也检查了 [VCSL](https://github.com/sgossner/VCSL)；它适合继续补键盘、拨弦、竖笛等，但没有直接覆盖这三件管弦乐器的整套替代。不要将网站可免费试听／导出与允许再分发底层采样混为一谈。未来可研究其他作者库，但需要重新逐项确认授权和映射，不因搜索页写“免费”直接打包。

## 转换与行为

采集命令：安装 `tools/audio-audit-requirements.txt` 后运行 `python tools/collect-orchestra-expansion.py --selection complete-trio`。默认 `expanded` 保持原有采集目标。原始录音与工作 WAV 分目录忽略 Git，元数据、SFZ、授权须提交。

转换为 48 kHz 双声道 PCM16，整套统一 -6 dB，保留全部时长；每件乐器再使用一个统一的音量余量，保持作者各力度录音之间的相对关系。原录音中无满幅采样的 273 份通过本轮技术筛选；这不是对主观音色的认证。作者的随机窗口采用引擎的确定性交替，固定种子可复现，不承诺逐样本复刻 SFZ 引擎的行为。没有虚构无限延音，音符长于原录音时会自然结束。

`tools/builtin-complete-orchestra.mjs` 生成完整乐器；`tools/builtin-velocity-regions.mjs` 将不同交替录音的力度边界分割为一致区间，避免后来的录音永远选不到。新 ID 为 `instrument-vsco-solo-violin`、`instrument-vsco-clarinet`、`instrument-vsco-trombone`。三件完整定义替换九个旧乐器入口；历史组合示例和用户保存的快照不自动重写。

录音以完整 PCM 内容 ID 共享，乐器只是引用；单独录音与乐器的声音身份相同。分享必须带全部依赖，不能只打包当前弹过的几个音符。不可修改既有内容 ID 下的声音。个人资源和官方资源的保存规则仍见多音库交接。

1. 先列当前目录的缺口，不按文件数扩库。剩余旧乐器如竖琴、萨克斯等仍需评估；弦乐组、长笛、圆号、小号的旧扩充入口也尚未统一成此次的完整定义。

3. 在下载前读取授权原文，确认允许把原始采样放进可公开再分发的库；记录作者、许可 URL、固定提交、源文件与映射哈希。无法确认时不进入内置库。
4. 保留所有原件，审查音区／力度／演奏方式，独立解码并重放转换，检查静音、满幅、极低音量、尾部和映射可达性。测试边界与未播放音符的离线分享。数值检测不能冒充听审。
5. 先恢复旧 `archive` 输入，再生成候选包和新版本 Release；空缓存从正式 URL 恢复通过后，提交匹配锁文件和目录。运行音库先发布，主站后发布。完整命令和两个仓库职责见维护流程。
6. 分类扩库可以另外发布一个 `momo.remote-sound-library/v1` 目录，配置多个 URL。GitHub Pages、CDN、对象存储只要满足 HTTPS、CORS 和静态文件协议均可；不能把多个库理解成无限免费空间。保持每个站点体积检查，不调高上限绕过限制。
