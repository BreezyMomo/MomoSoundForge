# 原创试听对比索引

音符数据在 ../../assets/lesson-recipes.json；用离线 CLI 的 lesson 与 render 命令生成原生工程和 WAV。每组只改变列出的因素；试听后再解释，不能将数值峰值匹配视为等响度证明。

## E01 频率与音高

配方：e01-a / e01-b。

改变：音高。保持：节奏、音色与渲染设置；最终数字峰值匹配。

听什么：比较高低，不把较高误认为较响。

## E02 八度移调

配方：e02-a / e02-b。

改变：整体加十二半音。保持：节奏、音色与渲染设置；最终数字峰值匹配。

听什么：轮廓保留，音域提高；各音频率恰为两倍。

## E03 有序音阶

配方：e03-a / e03-b。

改变：顺序由上行改下行。保持：节奏、音色与渲染设置；最终数字峰值匹配。

听什么：音集相同，旋律方向不同。

## E04 半音与全音

配方：e04-a / e04-b。

改变：第二音高一半音。保持：节奏、音色与渲染设置；最终数字峰值匹配。

听什么：E–F 是半音，E–F♯ 是全音。

## E05 级进与跳进

配方：e05-a / e05-b。

## E06 摇篮曲轮廓

配方：e06-a / e06-b。

听什么：两句都收在 C，比较窄音域与宽起伏；不是完整摇篮曲配器。

## E07 号角选音

## E08 主音落点

配方：e08-a / e08-b。

## E09 删去收束音

## E10 问答结构

听什么：相同开头的两句，B 第二句回到中心。

## E11 动机移调

听什么：节奏和精确音程保持；B 的 F♯ 是移调结果，不叫 C 大调调内模进。

## E12 相对大小调中心

听什么：两句都只用白键；这不是只改一个音的严格控制实验。

## E13 同主音大小调

## E15 黑键五声

## E16 都节两个半音

听什么：B 为 C 都节教学音集，观察 C–D♭ 与 G–A♭。

## E17 视频的蓝音降音实验

## E18 小调五声加入蓝音

## E19 离散音与弯音

配方：e19-a / e19-b。

改变：第二音由 E♭ 连续上滑到 E。保持：节奏、音色与渲染设置；最终数字峰值匹配。

听什么：这是完整音符期间的合成滑音，解释弯音机制，不模拟真实推弦。

## E20 希贾兹下方四音

配方：e20-a / e20-b。

听什么：B 的 D♭–E 为增二度，两侧 C–D♭、E–F 为半音；十二平均律近似。

## E21 视频希贾兹音集

配方：e21-a / e21-b。

听什么：标记一、三、一、二、一、二、二半音结构；非完整 maqam 演奏。
