# 首版实现与验证

2026 年 11 月 4 日。

本次实现了可运行的本地浏览器音效工具，范围为分层合成、采样组合、变体、工程和 WAV 交付。功能入口、启动方式及当前边界见 [README](../README.md)。没有推送或上线部署。

## 结构

声音工程采用 `momo.soundforge/v4`：文档持有 root 播放器，父组合 inputs 管理子播放器的读取与编排。旧未发布格式不再读取。当前字段、时长、保存与替换规则见 [播放器结构](sound-design-plan.md)。采样仍内嵌，每级 16 路、6 级嵌套、总计 128 路、全部层级共享 24 MiB 采样预算，并拒绝循环依赖。

DSP 是确定性纯函数。Web Worker 在后台执行同一函数，结果供波形、AudioBuffer 播放和 WAV 导出共用。变体逐个记录工程快照、种子和渲染结果；修改主作品后保留旧变体并提示版本差异。锁定层的噪声种子与参数均保持不变。

组合层递归渲染子工程的立体声输出，再应用外层时间窗口、速度、包络和处理。默认外层音量、声像及处理为中性值，保留子工程的主音量与回声。编辑路径通过稳定层 ID 定位，修改时逐级生成父工程快照，使复制实例独立；撤销、自动草稿与顶部保存始终使用完整根工程。子级编辑器可独立保存当前子音效，并通过路径返回父级。采样 ID 仅在所属工程内解析。

本地声音库将 IndexedDB 升级到版本 2，保留原 drafts 仓库。sounds 保存完整可编辑快照，sound-index 仅保存名称、时长、递归层数和小型波形预览，浏览列表不加载全部采样。保存时在同一事务内更新内容和索引；同名更新明确选择，另存副本生成独立 ID。试听、打开和添加时才读取工程；移除只标记索引，可从最近移除恢复。声音库不进入作品撤销历史，现有实例不引用可变库记录。

React portal 挂载到稳定工作台容器；停靠与切换页签不重新创建音频编辑器。布局、外观和语言使用 `@momo/workbench` 0.2.0 的发布包，产品注册自己的面板、词库与存储键，没有修改共享包。

时间轴支持片段移动和两端拉伸。指针捕获保证拖出轨道仍能完成操作，拖动草稿仅在片段内预览，松手后原子提交一次工程修改；Esc、指针取消或目标参数被其他操作改变时放弃草稿，不向工程或历史写入中间值。边缘限制最短 0.01 秒，默认按 0.01 秒调整，Shift 使用 0.001 秒。单层播放按钮独立试听该层，不等待编排中的开始时间。

合成波形提供始终可见的播放头，支持点击、指针拖动、方向键与首尾定位。定位、暂停与继续播放复用原渲染缓冲区，通过 AudioBufferSource 的起播偏移完成；播放位置独立于工程和撤销历史。切换循环时按当前相位重新计算时钟基线，避免循环数导致显示跳到末尾。

## 浏览器验证

已使用实际界面完成：

- 开启循环、试听、观察播放位置并停止。
- 生成五个变体并试听。
- 导入生成的真实 WAV，出现第 5 个采样层，调整采样倒放与速度并撤销。
- 保存携带采样的工程，再从下载文件重新打开，恢复全部 5 层和 1 个内嵌采样。
- 切换英文，固定文案和工作台同步更新，工程名称和声音层名称保留。
- 下载主 WAV 和五变体 ZIP；用 `tools/verify-delivery.mjs` 逐字节验证主 WAV 及五个变体 WAV 与对应保存工程的重新渲染完全一致。
- 使用真实指针拖动主体片段，从 0.12 秒移动到 0.22 秒，再分别调整左右端；属性面板同步起点与时长，三次撤销分别恢复三次完整拖动。
- 点击波形定位到 0.250 秒，再拖到 0.150 秒；从指定位置播放、暂停保留、从暂停处继续、播放中跳转后继续，以及播放中回到开头均已通过实际界面验证。
- 将冰晶命中组合为一层，进入子级修改频率并撤销、重做；在子级使用顶部保存后确认仍包含完整根工程。
- 嵌入含采样的 v1 工程，继续嵌套，返回根级调整整体位置，保存后重新打开；子级层和采样均恢复。撤销进入中的组合操作后自动返回仍存在的父级。
- 在子级点击“保存此音效”，确认下载工程仅含该子级及其完整下级组合、声音层和内嵌采样。
- 重新加载页面、尚未试听时，在子级直接导入 WAV，确认新增采样层。解码与播放启动分开，文件选择器在异步读取完成后重置。
- 下载嵌套工程的主 WAV 和五变体 ZIP，逐字节验证六个 WAV 与其各自完整工程重新渲染一致：根级 2 层、递归共 10 层、1 个内嵌采样，主 WAV 307244 字节。
- 保存含嵌套和采样的音效到声音库，直接试听、刷新后读取、添加到另一作品、修改实例后重新打开原件；验证原件保持独立。另存副本、重命名、移除和恢复，以及独立导出完整工程均通过实际界面验证。
- 在组合内部独立保存 5 层子音效；中英文切换保持用户名称；390 像素宽度下检查我的音效列表和中英文同名保存窗口，操作完整可见。

下载校验结果：5 个声音层、1 个采样；主 WAV 307244 字节；5 个变体 WAV 全部与各自工程一致。

自动测试覆盖全部预设的有限值、时长、非静音、末端归零和峰值边界，固定种子、锁定噪声、零变化、静音、独奏、声像、立体声、采样编解码、倒放/裁剪、输入拒绝、WAV 头和 PCM 内容，以及中英词库一致性。

声音库版本共 35 项测试，另覆盖组合参数与立体声保留、整体偏移、复制实例独立编辑、时长跟随、各级同名采样 ID、递归资源清理、v1 迁移、循环/深度/全局资源预算拒绝，以及声音库数据库升级、独立快照、更新恢复和内容/索引原子回滚。

## 界面设计记录

使用 design-taste-frontend 的应用编辑器流程。方向为 True-black flat，种子 `1820865035`，保留系列字体与工作台结构，未重抽方向。采用中性深色层级，声音波形使用单一浅蓝色；声音层的时间片段是产品特征，主操作是试听。

1440、768、390 像素宽度均已实际截图检查。桌面显示预设、分层作品、属性和变体；窄屏切换四个工作区页签。检查器无失败项；保留紧凑编辑器中 11–12px 的时间、参数与辅助文案提示。层号用于对应轨道，导出文件的序号用于稳定排序；声源类型说明用于区分合成与采样。

播放头版本的颜色占比检查提示数据着色较少；截图中的实时 Canvas 波形仍保持单一浅蓝色，尾部接近静音时按真实幅度显示，不为增加着色面积改变声音数据。
